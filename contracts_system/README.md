# Система управления контрактами на животных

## 📋 Описание

Автоматизированная система для загрузки, валидации и версионирования Excel-файлов с данными о контрактах на животных. Предназначена для работы аналитиков с файлами в формате `.xlsx`.

## 🚀 Возможности

- **Валидация данных**: Проверка структуры, типов данных, обязательных полей, уникальности и справочников
- **Версионность**: Автоматическое сохранение версий файлов с историей изменений
- **Сравнение версий**: Отчеты о добавленных, удаленных и измененных записях
- **Отчетность**: Генерация текстовых отчетов по истории версий
- **Контроль целостности**: Проверка полноты и корректности данных перед сохранением

## 📁 Структура проекта

```
contracts_system/
├── config.py              # Конфигурация и правила валидации
├── validator.py           # Модуль валидации Excel файлов
├── version_manager.py     # Управление версиями файлов
├── main.py                # Основной CLI скрипт
├── uploads/               # Папка для загрузки новых файлов
├── versions/              # Хранилище версий файлов
├── reports/               # Генерируемые отчеты
└── logs/                  # Логи системы
```

## 💡 Использование

### 1. Загрузка нового файла

```bash
python main.py upload <путь_к_файлу> --version <версия> --description "Описание изменений"
```

Примеры:
```bash
# Загрузка первой версии
python main.py upload contracts.xlsx --version 1.0.0 --description "Первая версия контрактов"

# Загрузка новой версии (версия определится автоматически)
python main.py upload contracts_updated.xlsx --description "Добавлены новые животные"
```

### 2. Валидация файла (без загрузки)

```bash
python main.py validate <путь_к_файлу>
```

Пример:
```bash
python main.py validate contracts.xlsx
```

### 3. Просмотр истории версий

```bash
python main.py history <имя_файла>
```

Пример:
```bash
python main.py history contracts.xlsx
```

### 4. Сравнение двух версий

```bash
python main.py diff <имя_файла> <версия1> <версия2>
```

Пример:
```bash
python main.py diff contracts.xlsx 1.0.0 1.0.1
```

### 5. Генерация отчета

```bash
python main.py report
```

## 📊 Правила валидации

По умолчанию настроены следующие поля:

| Поле | Тип | Обязательное | Уникальное | Описание |
|------|-----|--------------|------------|----------|
| contract_id | STRING | ✅ | ✅ | Уникальный ID контракта |
| animal_name | STRING | ✅ | ❌ | Кличка животного (1-100 символов) |
| species | STRING | ✅ | ❌ | Вид (Собака, Кошка, Птица, Грызун, Рептилия, Другое) |
| birth_date | DATE | ✅ | ❌ | Дата рождения (ГГГГ-ММ-ДД) |
| weight | FLOAT | ❌ | ❌ | Вес в кг |
| owner_name | STRING | ✅ | ❌ | ФИО владельца |
| is_active | BOOLEAN | ✅ | ❌ | Статус контракта (True/False) |
| notes | STRING | ❌ | ❌ | Примечания |

### Настройка правил

Для изменения правил валидации отредактируйте файл `config.py`:

```python
ANIMAL_CONTRACT_COLUMNS = [
    ColumnRule(
        name="your_column",
        dtype=DataType.STRING,  # или INTEGER, FLOAT, DATE, BOOLEAN
        required=True,          # обязательное поле
        unique=False,           # требуется уникальность
        min_length=1,
        max_length=100,
        allowed_values=["value1", "value2"],  # справочник
        description="Описание поля"
    ),
    # ... другие поля
]
```

## 🔄 Рабочий процесс аналитика

1. **Подготовка файла**: Аналитик заполняет Excel-файл по шаблону
2. **Загрузка**: Копирует файл в папку `uploads/`
3. **Валидация**: Запускает `python main.py upload файл.xlsx`
4. **Исправление ошибок** (если есть): Система покажет ошибки, аналитик исправляет файл
5. **Повторная загрузка**: После исправления файл загружается снова
6. **Просмотр истории**: При необходимости можно посмотреть историю изменений

## 📞 Поддержка

При возникновении проблем проверьте:
1. Наличие всех зависимостей (`pip list`)
2. Корректность пути к файлу
3. Формат Excel файла (.xlsx, не .xls)
4. Кодировку файла (должна быть UTF-8 для текстовых полей)
